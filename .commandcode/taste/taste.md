# Taste

## UI components

- For side-panel form/editor flows, prefers the project's shared `Drawer` component over `Sheet`. Confidence: 0.65
- Prefers row action buttons in tables collapsed into an ellipsis (kebab/overflow) menu instead of inline icon buttons. Confidence: 0.5
- Prefers reference/relation dropdowns to be searchable (searchable combobox) rather than plain select menus. Confidence: 0.55

## Coding style & workflow

- Expects changes to analogous variants handled together: when a UI/behavior fix is made for one case (e.g. "rak"), apply the same treatment to sibling cases (kardus, pallet) without being asked. Confidence: 0.55
